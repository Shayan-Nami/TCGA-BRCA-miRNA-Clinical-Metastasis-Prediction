# Dataset Information 🧬


### How to run the code:
1. Download the dataset files from your source (or GDC Portal).
2. Place the following files in this directory:
   - `Human_TCGA_BRCA_..._miRNASeq.cct` (miRNA Data)
   - `Human_TCGA_BRCA_..._Clinical.tsi` (Clinical Data)

> **Note:** The script `BRCA_GNB_PCA_LDA_QDA.ipynb` is configured to read files from this `data/` folder automatically.
